# SupeRR Selector — Auction Intelligence

Interactive GitHub Pages dashboard for IPL 2027 auction preparation.

- Primary ranking: 80% Pressure Performance + 10% Injury/Fitness + 10% RR Fit.
- Alternate views: PP only and 90% PP + 10% Injury/Fitness.
- Searchable batter and bowler tables, player profiles, ranking comparison, weight sensitivity, RR auction strategy and bid-room diligence checklist.
- Data cut-off: 17 November 2026.

Important: released does not mean registered. Sikandar Raza and Mark Chapman are uncontracted prospects with registration unconfirmed. Injury score 50 is a neutral placeholder where evidence is incomplete; it does not mean confirmed fitness. RR-fit values are analyst assessments. Confirm final auction registration and medical status before bidding.
